# PTB-XL Model training

This repo contains my solution for the challenge "PTB-XL Model training proposed by Idoven". For further details, you can take at the README.md file

## Prev requirements
Please make sure docker is installed in your environment so that the program can be properly executed


# How to:

### Notebook

This profile would show a more explainable process of how the solution has been reached, with certain explainations on a notebook. You should be able to reach the notebook in the main folder `FernandoVelasco.ipynb` and you would also be able to reproduce the steps to reach the solution. Please note no reproductibility/seeds have been used as the main aim has not been finding the best solution but experiment with more than one. 


```
docker compose --profile ecg_notebook build
docker compose --profile ecg_notebook up
```

You'll be able to access the jupyter notebook server on your `http://127.0.0.1:8888/`
